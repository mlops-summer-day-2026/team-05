# Как показать продукт залу

## Вариант А — одностраничный сайт

GitHub Pages для вашего репозитория **уже включён**. Ничего настраивать не надо.

1. Положите `index.html` в корень репозитория (не в подпапку)
2. `git add -A && git commit -m "деплой" && git pull --rebase && git push`
3. Через минуту открывается https://mlops-summer-day-2026.github.io/__TEAM__/

Сделайте это в первые десять минут с пустой страницей. Пусть там будет одно слово —
важно убедиться, что труба работает, пока есть время чинить.

**Проверки перед защитой:**

- Открывается **с телефона по мобильному интернету**, а не только с ноутбука по вайфаю
- Кнопки нажимаются пальцем, шрифт читается с трёх метров
- Работает после жёсткого обновления страницы — то есть не держится на том, что осталось
  в памяти вкладки

**Если страница не обновляется:** GitHub Pages обновляется примерно минуту после пуша.
Дальше это кеш браузера, помогает обновление с сбросом кеша или открытие в приватном окне.

**Если 404:** файл называется именно `index.html`, лежит в корне, и коммит реально
улетел на GitHub — проверьте на странице репозитория.

## Вариант Б — телеграм-бот

1. Напишите @BotFather, команда `/newbot`, получите токен
2. Токен в `.env` в переменную `TELEGRAM_BOT_TOKEN`
3. Бот запускается с ноутбука команды и живёт, пока ноутбук открыт

Минимальный каркас, который Claude достроит под ваш сценарий:

```bash
python -m venv .venv && source .venv/bin/activate && pip install aiogram python-dotenv
```

**Важно для демо:** бот работает, только пока запущен процесс на ноутбуке. Не закрывайте
крышку перед выходом на сцену и не уходите в спящий режим. Ссылку на бота (`t.me/имя_бота`)
дайте тестировщикам и диверсантам сразу — им будет чем заняться.

## Страховка на случай, если демо упадёт

За пятнадцать минут до защиты **запишите видео экрана**, где всё работает. Двадцать
секунд, телефоном или встроенной записью экрана.

Если на сцене вайфай ляжет, вы покажете запись и продолжите. Если всё хорошо — запись
не понадобится, вы потеряли двадцать секунд. Обмен выгодный.

По правилам живое демо ценится выше, так что показывайте живое, пока оно работает.
Запись — это парашют, а не основной план.
