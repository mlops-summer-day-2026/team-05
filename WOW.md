# Вау-слой: готовые вызовы

Карта 2 требует хотя бы один сенсорный элемент — сгенерированный голос, картинку,
видео или музыку. Ниже рабочие заготовки, чтобы не читать документацию четырёх сервисов.

**Проверьте один вызов в первые десять минут.** Не в последние двадцать. Если сервис
не отвечает, лучше узнать об этом, пока есть время переиграть.

---

## Правило, которое спасает демо

**Сгенерируйте медиа заранее и положите файлом в репозиторий.** Голос заказчика,
картинка-заставка, джингл — всё, что не обязано генерироваться в реальном времени,
должно лежать готовым.

На сцене интернет тормозит, API отвечает пятнадцать секунд, а у вас три минуты.
Живая генерация уместна там, где она и есть аттракцион: зритель ввёл слово, продукт
выдал картинку. Всё остальное — заранее.

---

## Ключи

Ключи лежат в `.env`. Из статической страницы прочитать `.env` нельзя, поэтому для
варианта с одностраничником есть два пути:

1. **Вставить ключ прямо в JS** — быстро, но ключ виден любому, кто откроет исходники
   страницы. На мероприятии с лимитом трат это допустимо, но знайте, что делаете
2. **Вызывать API из телеграм-бота**, где ключ остаётся на вашем ноутбуке — безопасно
   и без возни с CORS

Скажите об этом агенту прямо, иначе он сам выберет вариант и не скажет какой.

## Текст и диалоги — OpenRouter

Один ключ на сотни моделей. Работает из браузера.

```js
const r = await fetch("https://openrouter.ai/api/v1/chat/completions", {
  method: "POST",
  headers: {
    "Authorization": `Bearer ${OPENROUTER_API_KEY}`,
    "Content-Type": "application/json"
  },
  body: JSON.stringify({
    model: "google/gemini-2.5-flash",
    messages: [{ role: "user", content: "Придумай смешной комплимент для Ани" }]
  })
});
const data = await r.json();
console.log(data.choices[0].message.content);
```

Если в ответ прилетела ошибка про несуществующую модель — идентификаторы моделей
меняются, возьмите актуальный со страницы https://openrouter.ai/models и подставьте.
Для скорости берите модели с пометкой flash или mini, они отвечают за секунду.

## Картинки — fal.ai

Самый быстрый вариант для живой генерации, ответ за пару секунд.

```js
const r = await fetch("https://fal.run/fal-ai/flux/schnell", {
  method: "POST",
  headers: {
    "Authorization": `Key ${FAL_KEY}`,
    "Content-Type": "application/json"
  },
  body: JSON.stringify({ prompt: "кот в костюме астронавта, мультяшный стиль" })
});
const { images } = await r.json();
document.querySelector("img").src = images[0].url;
```

## Голос — ElevenLabs

Идентификатор голоса берётся в интерфейсе ElevenLabs, в библиотеке голосов.
Для русского нужна мультиязычная модель.

```js
const r = await fetch(`https://api.elevenlabs.io/v1/text-to-speech/${VOICE_ID}`, {
  method: "POST",
  headers: {
    "xi-api-key": ELEVENLABS_API_KEY,
    "Content-Type": "application/json"
  },
  body: JSON.stringify({
    text: "Аня, ты сегодня великолепна",
    model_id: "eleven_multilingual_v2"
  })
});
const blob = await r.blob();
new Audio(URL.createObjectURL(blob)).play();
```

Браузер не даст проиграть звук до первого клика пользователя. Вешайте воспроизведение
на кнопку, иначе на сцене будет тишина и непонимание.

## Видео и музыка — Replicate

Генерация идёт от десятков секунд до минут, для живого демо не годится. Используйте,
чтобы подготовить ролик заранее.

```bash
curl -s -X POST https://api.replicate.com/v1/predictions \
  -H "Authorization: Bearer $REPLICATE_API_TOKEN" \
  -H "Content-Type: application/json" \
  -H "Prefer: wait" \
  -d '{"version": "<id модели с replicate.com>", "input": {"prompt": "..."}}'
```

Заголовок `Prefer: wait` держит соединение до готовности, иначе придётся опрашивать
статус в цикле.

## Когда браузер отказывается звонить в API

Симптом: в консоли ошибка со словом CORS, запрос не уходит. Значит, сервис не
разрешает вызовы напрямую из браузера. Варианты по скорости решения:

1. Сгенерировать медиа заранее и положить файлом — тридцать секунд
2. Перенести вызов в телеграм-бота, там ограничений нет
3. Взять другой сервис из списка выше

Не тратьте на это полчаса. Вау-слой — это один балл, а сломанное демо — минус пять.

---

## Идеи, которые дёшево дают вау

- Продукт **озвучивает имя заказчика** — плюс балл по критериям, если пасхалка с именем
- Аватарка или иллюстрация **генерируется под введённый текст** прямо на сцене
- **Фоновая музыка**, сгенерированная заранее, включается на старте демо
- Голосовой ввод через встроенное в браузер распознавание речи — бесплатно и без API
- Конфетти, тряска, звук — микроанимации ничего не стоят, а зал реагирует
