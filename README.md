# team-05 · Вайбкодинг-тимбилдинг «Строим для своих»

**14 августа 2026** · [Правила, тайминг, все команды](https://github.com/mlops-summer-day-2026)

Что строить и на чём — решает команда: сайт, телеграм-бот, что-то своё на питоне.
Важно одно: через два часа заказчик тыкает работающее демо со сцены, а зал видит его
с телефонов. Всё остальное — детали.

---

## Старт за 5 минут

Делает каждый, кто будет писать код. Тестировщикам и заказчику хватит ссылки на демо.

**1. Прими приглашение в организацию** — оно на почте, либо тут:
https://github.com/orgs/mlops-summer-day-2026/invitation. Без этого не запушишь.

**2. Поставь Claude Code**

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

Windows (PowerShell): `irm https://claude.ai/install.ps1 | iex`
Не любишь терминал — [десктопное приложение](https://claude.ai/download) делает то же самое кнопками.

**3. Залогинься подпиской** — запусти `claude`, войди в браузере учёткой Pro или Max.

**4. Поставь GitHub CLI** — `brew install gh` (macOS) или `winget install GitHub.cli` (Windows), затем:

```bash
gh auth login
```

**5. Забери репозиторий**

```bash
gh repo clone mlops-summer-day-2026/team-05 && cd team-05 && git config core.hooksPath .githooks
```

Хвост команды включает защиту от случайного коммита ключей — репозиторий публичный.

**6. Положи ключ**

```bash
cp .env.example .env
```

Вставь в `.env` ключ OpenRouter из чата капитанов.

**7. Запусти Claude**

```bash
claude
```

Первый промпт — скопируй как есть:

```
Прочитай AGENTS.md. Задай мне вопросы, чтобы заполнить пропуски: продукт, заказчик,
боль, стек. Запиши файл и предложи план на первые 30 минут.
```

## Как показать демо

**Самый короткий путь — статичная страница.** Положи `index.html` в корень, запушь —
через минуту она живёт на https://mlops-summer-day-2026.github.io/team-05/ и открывается
с любого телефона. Ничего настраивать не надо, уже включено.

**Телеграм-бот** — токен у @BotFather за 30 секунд, бот живёт, пока запущен на вашем
ноутбуке. Не закрывайте крышку перед выходом на сцену.

**Что-то своё** — ваше право, только продумайте заранее, как это увидит зал.

Каким бы ни был путь: **проверьте трубу в первые 10 минут**. Пустая страница с одним
словом или бот, отвечающий «привет» — неважно. Убедиться, что демо доезжает до телефона,
надо сейчас, а не за двадцать минут до защиты. И за 15 минут до выступления запишите
видео работающего продукта — это парашют на случай, если вайфай ляжет на сцене.

## Если что-то сломалось

**`claude: command not found`** — перезапусти терминал. Не помогло: добавь `~/.local/bin` в PATH.

**Не пускает пушить** — не принято приглашение (шаг 1) или нет `gh auth login` (шаг 4).

**`! [rejected] ... fetch first`** — кто-то запушил раньше тебя: `git pull --rebase && git push`.

**Страница не обновляется** — Pages пересобирается около минуты, дальше это кеш:
жёсткое обновление или приватное окно.

**Агент снёс чужой код** — `git log --oneline`, найди живой коммит, `git revert <хеш>`.
Запушенное не пропадает никогда, оно лежит на GitHub.

**Ключ перестал работать** — скорее всего утёк в публичный код и отозван. Сразу в чат
капитанов, не гадайте.
