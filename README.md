## Старт за 5 минут

Делает каждый, кто будет писать код. Если ты тестировщик или заказчик — тебе хватит шага 1 и ссылки на демо.

### 1. Прими приглашение в организацию

Приглашение пришло на почту. Если письмо потерялось — открой https://github.com/orgs/mlops-summer-day-2026/invitation, там висит кнопка Join. Без этого не сможешь запушить код.

### 2. Поставь Claude Code

macOS / Linux / WSL:

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

Windows (PowerShell):

```powershell
irm https://claude.ai/install.ps1 | iex
```

Не любишь терминал — [ставь десктопное приложение](https://claude.ai/download), там то же самое, но с кнопками.

Проверка:

```bash
claude --version
```

### 3. Залогинься подпиской

Запусти `claude`, откроется браузер, войди своей учёткой Pro или Max. Ключ API не нужен, платит подписка.

### 4. Поставь GitHub CLI и залогинься

Это избавляет от плясок с паролями при пуше. macOS: `brew install gh`, Windows: `winget install GitHub.cli`.

```bash
gh auth login
```

Выбирай GitHub.com → HTTPS → Login with a web browser.

### 5. Забери репозиторий

```bash
gh repo clone mlops-summer-day-2026/__TEAM__ && cd __TEAM__ && git config core.hooksPath .githooks
```

Последняя часть включает хук, который не даст случайно закоммитить ключи. Репозиторий публичный, утёкший ключ отзовут за минуты.

### 6. Положи ключи

```bash
cp .env.example .env
```

Открой `.env` и вставь ключи из чата капитанов. Файл `.env` в `.gitignore`, в репозиторий он не попадёт.

### 7. Запусти Claude и заполни контекст

```bash
claude
```

Первый промпт — скопируй как есть:

```
Прочитай AGENTS.md и PARALLEL.md. Задай мне вопросы, чтобы заполнить пропуски
в AGENTS.md: продукт, заказчик, боль, стек. Потом запиши файл и покажи, что получилось.
```

Дальше — стройте.

Порядок именно такой, он экономит потом полчаса.

- [ ] **Заполнили `AGENTS.md`** — это общий контекст, его читают все агенты в команде

## Если что-то сломалось

**`claude: command not found`** — перезапусти терминал. Не помогло: `~/.local/bin` не в `PATH`, добавь строкой `export PATH="$HOME/.local/bin:$PATH"`.

**Не пускает пушить, `permission denied`** — не принято приглашение в организацию (шаг 1) или не сделан `gh auth login`.

**`! [rejected] ... fetch first`** — кто-то запушил раньше. Лечится одной командой: `git pull --rebase && git push`.

**Демо не открывается по ссылке** — проверь, что `index.html` лежит в корне репозитория, а не в подпапке. После пуша страница обновляется примерно минуту. На телефоне помогает жёсткое обновление.

**Агент снёс чужие правки** — `git log --oneline` найдёт последний нормальный коммит, `git revert <хеш>` откатит. Не паникуйте и не удаляйте папку: всё, что было запушено, лежит на GitHub.

**Ключ перестал работать посреди билда** — скорее всего, он утёк в публичный репозиторий и был отозван. Пишите в чат капитанов, не тратьте время на догадки.
