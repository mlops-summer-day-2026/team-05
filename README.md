## Что происходит

Команда выбирает заказчика среди своих, вытаскивает его настоящую рабочую или бытовую
боль и за отведённое время строит продукт, который эту боль закрывает. В финале — защита,
где заказчик сам тыкает продукт на сцене.

Что строить и на чём — решаете вы: сайт, телеграм-бот, что-то своё. Важно одно: в конце
должно работать живое демо, которое зал открывает со своих телефонов.

## Как устроен день

- **Круг болей.** Каждый называет свою боль, команда голосует. Чья победила — тот заказчик,
  его слово в спорных решениях последнее
- **Билд.** Основное время. Заказчик принимает фичи по ходу: «да» двигает дальше, «нет»
  экономит двадцать минут работы в стол
- **Вводные по ходу.** Ведущий несколько раз поменяет правила игры. К ним нельзя
  подготовиться заранее — просто держите запас времени и не уходите в себя
- **Защита.** Несколько минут на команду. Живое демо важнее слайдов
- **Баллы.** Жюри плюс голос зала. Смотрят, закрыта ли боль, работает ли демо на сцене,
  есть ли вау-эффект, и как зал реагирует

## Как не мешать друг другу

Главная опасность дня — не баги, а затёртая работа. Правила простые и работают при любом
раскладе:

- **Один файл — один хозяин.** Делите не задачи, а файлы: задачи неизбежно пересекаются,
  файлы — нет. Запишите раскладку в `AGENTS.md`, чтобы её видели и агенты
- **Нужна правка в чужом файле — скажите хозяину**, не лезьте сами. Полминуты разговора
  дешевле конфликта
- **Коммит каждые десять-пятнадцать минут** и перед каждым большим промптом:
  `git add -A && git commit -m "..." && git pull --rebase && git push`
- **Никогда `push --force`** — это то, чем стирают чужую работу
- **Кодить не обязаны все.** Тестировать демо с телефона после каждого деплоя, писать
  промпты текстом, пока пилот занят, собирать контент, репетировать питч — этой работы
  обычно не хватает больше, чем рук на клавиатуре

Подробнее — в [AGENTS.md](AGENTS.md), там же готовые вызовы API.

## Ключ

Один на всех — OpenRouter, через него и текст, и картинки. Голос дешевле и надёжнее брать
браузерным `speechSynthesis`: работает без интернета и без API.

Репозиторий публичный. Ключ, вписанный в JS статичной страницы, видно всем — на этом
мероприятии так можно, лимит трат стоит, но пусть это будет вашим решением, а не тем,
что агент сделал молча. В коммиты ключ не попадает: `.env` в `.gitignore`, плюс хук.

## Демо

**Статичная страница** — самый короткий путь. `index.html` в корень, пуш, через минуту
живёт по ссылке сверху и открывается с любого телефона. Pages уже включены.

**Телеграм-бот** — токен у @BotFather за полминуты, живёт пока запущен на ноутбуке.
Не закрывайте крышку перед выходом на сцену.

Перед защитой проверьте: открывается с телефона по мобильному интернету, кнопки жмутся
пальцем, шрифт читается с трёх метров. И **запишите видео работающего демо** заранее —
это парашют на случай, если вайфай ляжет на сцене.

## Если сломалось

**`! [rejected] ... fetch first`** — кто-то запушил раньше: `git pull --rebase && git push`

**Не пускает пушить** — не принято приглашение в организацию, ссылка выше

**Демо 404** — `index.html` должен лежать в корне, а не в подпапке. После пуша страница
собирается около минуты, дальше это кеш браузера

**Агент снёс чужой код** — `git log --oneline`, найти живой коммит, `git revert <хеш>`.
Запушенное не пропадает никогда

**Ключ перестал работать** — скорее всего утёк в публичный код и отозван. Сразу в чат
капитанов, не гадайте
