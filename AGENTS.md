## Как работаем втроём в одном репозитории

Главный риск дня — не баги, а затёртая работа друг друга.

- **Один файл — один хозяин.** Делим не задачи, а файлы. Раскладка ниже
- Все коммитят в `main`, без веток и пул-реквестов — на них нет времени
- Цикл каждые 10–15 минут и перед каждым большим промптом:
  `git add -A && git commit -m "..." && git pull --rebase && git push`
- Конфликт: разрулить маркеры → `git add . && git rebase --continue`.
  Запутался — `git rebase --abort` вернёт как было
- **Никогда:** `push --force`, `reset --hard` без разговора с командой, коммит `.env`
- Нужна правка в чужом файле — скажи хозяину, сам не лезь
- Два агента на одном ноутбуке — только через `git worktree add ../team-05-2`,
  две сессии в одной папке перетирают друг друга

## API

Ключ один — OpenRouter, лежит в `.env` (`OPENROUTER_API_KEY`). Через него и текст,
и картинки.

**Текст** (быстрые модели — flash/mini, актуальные id на openrouter.ai/models):

```js
const r = await fetch("https://openrouter.ai/api/v1/chat/completions", {
  method: "POST",
  headers: { "Authorization": `Bearer ${KEY}`, "Content-Type": "application/json" },
  body: JSON.stringify({
    model: "google/gemini-2.5-flash",
    messages: [{ role: "user", content: "..." }]
  })
});
```

**Картинки** — тот же endpoint, модель с генерацией изображений
(например `google/gemini-2.5-flash-image`), в запрос добавить `modalities: ["image", "text"]`,
картинка приходит в ответе как data-url.

**Голос — бесплатно, без API:** `speechSynthesis.speak(new SpeechSynthesisUtterance("текст"))`
прямо в браузере. Распознавание речи — тоже встроено (`webkitSpeechRecognition`).
Для пасхалок и комплиментов заказчику это надёжнее любого API.

Правила вау-слоя:

- Один проверенный вызов в первые 10 минут, не в последние 20
- Всё, что не обязано генерироваться на сцене — сгенерировать заранее и положить файлом
- Звук в браузере играет только после клика пользователя — вешай на кнопку
- Ключ в JS статичной страницы виден всем. На этом мероприятии допустимо (лимит стоит),
  но решение принимает команда, а не агент молча
